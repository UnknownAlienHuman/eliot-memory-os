# K2-1880 - #1880 [I7-audit] Enforce agent-facing transport-profile admission and loopback HTTP constraints

The bind/Host/Origin/route half of this issue is on `main` at `d1dbbb54` and must be preserved verbatim
(`transport_profile.rs::admit_loop_bind`, `validate_host`, `validate_origin`, `loopback_http_route`, `constant_time_eq`,
`MAX_HTTP_CREDENTIAL_TTL`). What is missing is the credential: `cli_contract::parse_args` takes a raw bearer out of argv,
`issue_loopback_credential` mints nothing, and `validate_loopback_bearer` hands the profile's own expected scope back
into `validate_credential`, so the scope check is tautological.

**Canonical:**

- [I7.5 named pipes](../../docs/architecture/I07-05-named-pipes.md#i75-named-pipes) — "The loopback HTTP profile binds
  only `127.0.0.1`/`::1`, requires a scoped short-lived bearer credential issued through local setup, enforces the same
  Session/authority contracts, and exposes no admin or database surface." … "Binding `0.0.0.0`, trusting loopback without
  host validation, or reusing the local credential remotely is forbidden. Losing the HTTP bridge does not affect Kernel or
  canonical state." Also line 11: "Each launched child also presents random nonce delivered via protected inherited
  handle/file, not command line."
- [I15.4 secrets](../../docs/architecture/I15-04-secrets.md#i154-secrets) — "secret values never in TOML, CLI args, model
  packet, logs, canonical memory or blobs; child receives only needed secret via protected handle/pipe; secret access has
  audit receipt without value; rotation invalidates dependent Sessions/modules."
- [I7.3 handshake](../../docs/architecture/I07-03-handshake.md#i73-handshake) — ServerHello carries "session/principal
  binding" and State/Authority Epoch; "Old generation cannot reconnect after epoch fencing."

**MAKE:**

1. Remove the `--http-credential`, `--http-credential=` and `--http-credential-ttl` arms from `parse_args` and refuse any
   remaining credential-bearing `--http-*` argument with a typed code, so no bearer value can reach argv, an error detail,
   a crash command string or a reusable environment snapshot.
2. Add one local credential owner/setup seam in `transport_profile.rs`: mint only after `admit_loop_bind` succeeded **and**
   `run_loopback_http_bridge`'s `TcpListener::bind(profile.bind_addr())` returned, from the existing OS CSPRNG
   (`WindowsInstallerSecretProvider::generate_secret`); deliver the secret only over one protected channel
   (`WindowsPlatform::protect_secret` DPAPI one-shot file, or `write_credential`/`read_credential` on a non-reserved
   Credential Manager key, or a protected inherited handle); publish outward only an opaque reference/receipt plus an audit
   receipt without value, with an entropy floor and an issuer identity.
3. Widen the commitment past `LoopbackCredential.scope = bind.canonical()` to listener incarnation + connection id +
   Session id + activation generation + Authority Epoch + client/profile identity, reusing the existing
   `crates/surfaces/eliot-mcp/src/core.rs::TransportRequestContext` field set. Issue after the bridge transport binding
   exists, or bind a pending credential atomically to the first authenticated Kernel attach — never during CLI parse.
4. Replace `validate_loopback_bearer`'s `validate_credential(presented, profile.credential_scope(), profile)` with observed
   facts: the accepted local endpoint from the accepted stream, the live `BridgeRunner::attach_view()` connection/session/
   generation/epoch, and the current credential generation/revocation state. The scope argument must be an observation,
   never the profile's own expected value; fail closed when no live attach binding exists.
5. Revoke the prior credential generation on reconnect, detach, session replacement and expiry so a stale bearer cannot
   authorize a new Session on the same `127.0.0.1:port`. Keep `constant_time_eq`, the 5-minute maximum, strict
   `Host`/`Origin`, the single `/mcp` route, the admin/database exclusion and the stdio default unchanged, and store
   owner-issued expiry/revocation evidence rather than wall-clock alone.
6. Add the focused proofs from the 2026-10-01 comment as inline test modules in the crate's own source files — neither
   `transport_profile.rs` nor `cli_contract.rs` has a test module on `main`, and no `bins/eliot-agent-bridge/tests/*.rs`
   path for this exists on `main` or is named by any canonical doc.
