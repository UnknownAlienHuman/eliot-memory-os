name: eliot-code-understanding
description: Ground code work in CodeCortex reports before proposing or applying changes.
---

For nontrivial code work, run a bounded CodeCortex scan for the task goal and use its file evidence, symbol evidence, diagnostics, verifier map, blast radius, and unknowns.

UnderstandingProof for code work must cite CodeCortex report refs, files to inspect or change, causal bridge from goal to code, expected verifiers, and blast radius acknowledgement.

If CodeCortex cannot provide an adapter result, report that adapter as unavailable instead of replacing it with an ungoverned raw tool path.
