# ELIOT Governor Antigravity Plugin

Official Antigravity plugin source for proactive ELIOT project memory, dynamic task roles, and authority rules.

The plugin intentionally contains no `mcp_config.json`. ELIOT MCP is registered separately with an absolute release-binary path and `--host antigravity`; Governor then binds the session to the host-neutral `dynamic_agent` profile. Host identity grants no task role. The skill resolves stable human-readable project keys through Governor, recalls before local exploration, and writes candidate-only handoff state after material work.
