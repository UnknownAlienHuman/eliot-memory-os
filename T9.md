### 1. Decision

**U1:** Governor owns the semantic inputs and introduction compilation, while Kernel owns activation, fencing and the compact executable projection; the worker may present and validate this evidence but cannot assemble missing authority locally (`docs/architecture/I06-15-capability-grant-lineage-introductions-and-resource-facets.md:3@7a1a6eaa`). The binding must preserve the existing admission saga—canonical admission, registered attempt and launch outbox first, matching Kernel activation second—and must not turn a valid claim digest into permission to launch (`docs/architecture/I10-15-agent-execution-fabric-and-durable-swarm.md:258@7a1a6eaa`). T4's `ProviderExecutionBinding` is the exact correlation of an execution unit that was started, not a replacement for the pre-start claim/permit join, so provider-returned execution-unit identity must not become a circular precondition or be fabricated from the process operation (`crates/agent/eliot-agent-api/src/execution_binding.rs:150@7a1a6eaa`).

**U2:** The production verification implementation belongs behind the existing sealed coordinator boundary, but “accepted A-01/G-11 adapter” does not specify a concrete authenticated capability, its issuing factory, receipt lookup or revocation context; that missing supplier contract remains an explicit prerequisite of #1108 (`crates/agent/eliot-agent-coordinator/src/core.rs:53@7a1a6eaa`). Catalogue presence, liveness, a public DTO or a self-computed digest cannot fill that prerequisite, because availability is not authority and logical routing is not physical execution evidence (`docs/architecture/I06-15-capability-grant-lineage-introductions-and-resource-facets.md:18@7a1a6eaa`; `docs/architecture/I10-11-external-model-bridges.md:122@7a1a6eaa`).

**U3:** Kernel/ORS owns operational recovery and cursor persistence, A-13 produces worker events through its existing injected replay port, and semantic observation processing must retain its existing canonical path rather than becoming a worker or ORS task journal (`crates/kernel/AGENTS.md:38@7a1a6eaa`; `crates/kernel/AGENTS.md:54@7a1a6eaa`; `crates/modules/eliot-native-worker-core/src/lib.rs:1@7a1a6eaa`). All five replay methods and the distinction between transport, durability, normalization and application acknowledgements must survive the transport mapping; claim reconciliation alone does not implement that contract (`crates/modules/eliot-native-worker-core/src/ports.rs:1037@7a1a6eaa`; `docs/architecture/I07-02-frame.md:66@7a1a6eaa`). Missing publisher, authenticated-supplier and stream/cursor declarations must be settled in the existing owners before dependent implementations run in parallel, not silently standardized by this brief (`docs/architecture/I02-17-parallel-agent-development-contract.md:3@7a1a6eaa`).

The lifecycle route implements registration, claim, ready, heartbeat, checkpoint, result submission and cancellation observation; the reconcile route operates on retained **claim** state. Their existence does not demonstrate persistence and transport for the worker's event stream, request acquisition and phased ACKs (`bins/eliot-kernel/src/native_worker_lifecycle_route.rs:1@7a1a6eaa`; `bins/eliot-kernel/src/native_worker_reconcile_route.rs:1@7a1a6eaa`).

| Existing method | Required lossless transport behavior |
|---|---|
| `lookup_request` | Read the exact stream/request/fingerprint identity without acquiring it or allocating an event. |
| `begin_request` | Atomically acquire a validated request or return the existing replay/conflict; after a crash, a retained acquisition cannot be treated as a fresh request merely because no response arrived. |
| `append` | Persist the draft under its exact bound stream, assign/retain durable event identity and sequence, and return only the persisted envelope. |
| `replay` | Return the retained suffix strictly after the supplied sequence, preserving identities, order, causal references and gaps; never silently truncate or return an empty success on incomplete storage/transport. |
| `acknowledge` | Verify the exact event, stream, generation, epoch, fence and phase, persist the disposition, and advance only the cursor allowed by the declared phase contract. |

The method signatures and request decision vocabulary are already fixed (`crates/modules/eliot-native-worker-core/src/ports.rs:1023@7a1a6eaa`). The table states obligations, **not invented wire operation names or a new return enum**.

**Missing statement M3, to be supplied by Kernel/ORS #15 with the A-13 producer and existing observation consumer:**

> Name the durable stream namespace and record owner; bind it to the admitted claim, producer, generation and operation; define the atomic acquisition/event-sequence relationship and exact outcomes for an acquired-but-unfinished request. Publish the closed request/reply mapping and version for all five existing methods, bounded replay/retention/gap behavior, and the producer/consumer cursor advanced by each ACK phase. State reconnect/generation-handoff authorization and the durable linkage to admissible raw/hash, normalized observation and disposition records without moving their semantic ownership into ORS.

The normative phases are `RECEIVED → DURABLE → NORMALIZED → APPLIED | REJECTED | UNKNOWN`. Do not infer that `RECEIVED` advances a durable cursor, that only `APPLIED` may ever advance every cursor, or that `UNKNOWN` is successful application. Those per-cursor declarations are explicitly required of the producer and consumer. Historical replay may survive generation replacement without restoring permission to execute under the old epoch (`docs/architecture/I07-02-frame.md:66@7a1a6eaa`; `docs/architecture/I07-23-raw-and-normalized-host-events.md:14@7a1a6eaa`).

**The first discriminator is an absent owner source, not Rust syntax.** T9-01 must trace every protected U1 field to a real current owner record and public source. T9-04 remains blocked until the exact production supplier and its admitted constructor are identified. Authenticated Kernel transport alone does not prove the semantic validity of a provider receipt.

**Schema convergence can regress source-compatible callers.** Worker/core and Kernel claim representations coexist; the agent API's actual exported revision is v6 despite older comments elsewhere. New bindings need explicit old-wire handling, consistent digest coverage and reverse-consumer checks. T9-02's first compatibility test must reject a formerly valid but insufficient claim without silently promoting it to launch authority.

**Replay can lose work without launching twice.** Preventing duplicate start is insufficient if an acquired request with no delivered event becomes an empty replay forever, or an ACK advances past missing raw/normalized evidence. T9-03's close/reopen and acquired-before-response cases must distinguish these states using the accepted M3 contract; no new worker-local journal or default success may conceal them.

**Pre-launch and provider execution identity can become circular.** M1 must bind what is known before launch; the existing provider-unit binding is attached and authenticated when that exact unit is known. Do not forge a provider turn to satisfy startup, and do not let a provider's later self-report retroactively authorize the process.

**Concurrent managers can invalidate the plan or race on shared files.** Before each implementation assignment, compare its exact source and instruction blobs with current `main`, re-read changed owner contracts, and serialize shared core/Kernel/coordinator exports, worker lib/main and root lockfile. The integration check at `main@f463f7efe9bce621fb85b5eef7766ab917806491` found four commits after the pin, with no changes to the cited U1/U2/U3 source or instruction files. Those later changes are preserved; they are not a replacement evidence snapshot for this brief.

**Proof ceiling:** this brief establishes a source-grounded owner/gap map and dependency plan. In particular, M1/M2/M3 and the dependent runtime issues must not be closed merely because `T9.md` was committed.
