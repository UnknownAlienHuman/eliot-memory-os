# Integration documentation

This directory contains current operator/developer documentation for concrete
core-repository integrations. It is subordinate to the canonical Architecture
and Implementation pair and does not define provider-independent semantics.

Integration documentation must describe an implemented or actively supported
core adapter. External product architecture belongs in that product's own
repository. Research notes, vendor audits, downloaded manuals, and speculative
provider comparisons belong in the owning issue/PR or external evidence store,
not here.

Current families:

- [`claude/`](claude/) — Claude Code/Desktop integration packaging and security.
