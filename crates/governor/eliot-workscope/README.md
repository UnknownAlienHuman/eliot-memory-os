# `eliot-workscope`

G-02 owns pure WorkScope identity, repository/workspace lineage evidence,
bounded discovery leases, deterministic onboarding outcomes, governing-source
sets, and `ScopeBindingGuard` revalidation.

The crate consumes caller-supplied observations and provider-owned C0-12
security contracts. It performs no filesystem, process, network, database or
credential IO; ambiguous, stale, conflicting and privacy-denied outcomes stay
typed and are never resolved by a hidden fallback.
